# تفاوت بین فایل و آگهی در ملک‌رادار 

## ۱. تفاوت «آگهی» و «فایل»
در پلتفرم **ملک‌رادار**، دو واژه **«آگهی»** و **«فایل»** به هیچ وجه هم‌معنی نیستند. هر چند بسیاری از مشاوران املاک ممکن است معنی این دو واژه را یکسان در نظر گیرند، ولی طبق توضیحات زیر این دو واژه از یکدیگر تفکیک می‌شوند:

| ویژگی | آگهی | فایل |
| :--- | :--- | :--- |
| **تعریف** | داده‌های خام جمع‌آوری‌شده از منابع بیرونی (سایت‌ها، شبکه‌های اجتماعی و...) | آگهی ملک پردازش‌شده، اعتبارسنجی شده و آماده معامله |
| **وضعیت** | تایید نشده و موقت | دارای تاریخچه و پایدار |
| **مخاطب** | سیستم پردازشگر درونی ملک رادار | مشاور املاک |
| **مثال** | آگهی دیوار، آگهی شیپور | فایل فروش، فایل اجاره |

> **خطای مصطلح:** هیچ‌گاه از عبارت «فایل دیوار» استفاده نکنید. شکل صحیح آن **«آگهی دیوار»** است. همچنین مشاور با **«فایل»** کار می‌کند، نه «آگهی خام».
