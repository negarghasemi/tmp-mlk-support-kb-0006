# زونکن فایل (رادار آگهی) چیست؟

## تعریف

**زونکن فایل** (زونکن رادار آگهی / زونکن آگهی) برای ذخیره‌سازی و دسته‌بندی **فایل‌های ملکی** شامل آگهی‌های **خرید**، **فروش** **و اجاره** طراحی شده است. این زونکن در بخش **رادار آگهی** اپلیکیشن ملک‌رادار قرار دارد.


## قابلیت‌ها

| قابلیت | توضیح |
| :--- | :--- |
| زونکن رایگان | هر مشاور ۳ زونکن فایل **رایگان** دارد؛ یک زونکن با نام «دم‌دستی» و دو زونکن با نام دلخواه |
| ظرفیت | تا ۲۰۰ فایل در هر زونکن |
| دسترسی | فایل‌ها همیشه روی موبایل یا مرورگر در دسترس مشاور است |
| مرتب‌سازی | مرتب‌سازی فایل‌ها بر اساس قیمت یا معیار دلخواه |
| ویرایش فایل | امکان به‌روزرسانی اطلاعات ملک (مانند شماره مالک) |
| زونکن «دم‌دستی» | فایل‌هایی که از طریق **بات** زونکن می‌شوند، به‌صورت خودکار در این زونکن قرار می‌گیرند |
| اشتراک‌گذاری تیمی | در نسخه **رادارپلاس**، زونکن‌ها بین همکاران بنگاه قابل اشتراک‌گذاری است (فقط‌خواندنی) |

---

### قوانین و محدودیت‌ها

- **تعداد** زونکن فایل رایگان برای هر کاربر: **۳ عدد**.
- **ظرفیت** هر زونکن فایل: **۲۰۰ فایل**.
- **خرید** زونکن فایل اضافه و **افزایش ظرفیت** از طریق اپ اندروید و اپ تحت وب امکان‌پذیر است.

### زونکن «دم‌دستی»
- زونکن پیش‌فرض هر کاربر است و نام آن قابل حذف یا تغییر نیست؛ اما فایل‌های داخل آن قابل حذف هستند.
- فایل‌های زونکن‌شده از طریق بات (دکمه زیر هر آگهی) به‌صورت خودکار در این زونکن ذخیره می‌شوند.

---

## پرسش‌های متداول

**سوال: هر زونکن فایل چند فایل می‌تواند داشته باشد؟**

پاسخ: ظرفیت هر زونکن فایل ۲۰۰ فایل است.

**سوال: آیا می‌توانم از طریق بات تلگرام فایل زونکن کنم؟**

پاسخ: بله؛ مشاورانی که عضو بات‌های ملک‌رادار هستند می‌توانند آگهی‌ها را از دکمه زیر هر آگهی در بات زونکن کنند. این فایل‌ها به‌طور پیش‌فرض در زونکن «دم‌دستی» ذخیره می‌شوند.
